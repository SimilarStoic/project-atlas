# Documentation

Start with [Conveyor Current State](CONVEYOR_CURRENT_STATE.md). It is the single current operational authority for
repository/runtime layout, product identity, production status, schema authority, known boundaries, and safe resumption.

Use the other documents by scope:

- [`../README.md`](../README.md) — concise repository onboarding and navigation.
- [`../ROADMAP.md`](../ROADMAP.md) — strategy and future sequencing only.
- [`../CURRENT_STATUS.md`](../CURRENT_STATUS.md) — historical status/provenance snapshot.
- [`CANONICAL_HANDOFF.md`](CANONICAL_HANDOFF.md) — historical handoff and governance provenance.
- [`evidence/experiments/REJECTED_V028_PROTOTYPES.md`](evidence/experiments/REJECTED_V028_PROTOTYPES.md) — rejected,
  non-canonical SimilarStoic v028 prototype evidence preserved as historical experiment context, not active production
  tooling.
- [`FOUNDER_PRODUCT_OPERATING_DOCTRINE.md`](FOUNDER_PRODUCT_OPERATING_DOCTRINE.md) — durable product and business
  judgement principles.
- [`BUSINESS_AND_VENDOR_STRATEGY.md`](BUSINESS_AND_VENDOR_STRATEGY.md) — bounded build-vs-buy, portability, provider,
  and commercial strategy; it does not authorize integration or spend.
- [`PERSISTENT_SCENE_MODEL.md`](PERSISTENT_SCENE_MODEL.md) — persistent-scene architecture and proof context.
- [`SIMILARSTOIC_VISUAL_VOCABULARY.md`](SIMILARSTOIC_VISUAL_VOCABULARY.md) and
  [`SIMILARSTOIC_CREATIVE_REFERENCE_SET.md`](SIMILARSTOIC_CREATIVE_REFERENCE_SET.md) — SimilarStoic creative
  vocabulary and reference interpretation.
- [`SIMILARSTOIC_PRODUCTION_NARRATOR.md`](SIMILARSTOIC_PRODUCTION_NARRATOR.md) — bounded SimilarStoic narrator
  authority.
- [`CONTROLLED_YOUTUBE_PILOT_ARCHITECTURE.md`](CONTROLLED_YOUTUBE_PILOT_ARCHITECTURE.md) and
  [`PUBLISHING_AND_LEARNING_LOOP.md`](PUBLISHING_AND_LEARNING_LOOP.md) — bounded design/provenance for publishing and
  learning; neither grants publication authority.

Historical design, experiment, quality-cycle, production, calibration, and disposition files remain evidence of how
the system evolved. Their dates and original claims must not be treated as live status when they conflict with
`CONVEYOR_CURRENT_STATE.md`.

Create `docs/decisions/` when the first architecture decision record is needed. Each decision record should state
context, decision, consequences, and alternatives.
